# Security & Privacy

## Reporting a vulnerability

Email **security@doingprocess.org** with details and steps to reproduce. Please
do not open a public issue for security or privacy matters. We aim to acknowledge
within a few days.

## Privacy model

This project processes sensitive material (scans that may carry a contributor's
legal identity). Please help keep the model intact:

- **No contributor data in the repo.** Scanned originals, uploads, and the corpus
  staging area are `.gitignore`d and must live in a restricted archive.
- **Legal identity is separated.** It exists only to handle the mail and is
  stripped before publication; only a private contributor ID links maps for credit.
- **Local-first.** Report any code path that sends a scan, draft, or contributor
  detail to a third-party service — that's a privacy bug, not a feature request.
